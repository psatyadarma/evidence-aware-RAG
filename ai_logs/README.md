# AI Assistance Logs

This directory contains exported AI-assisted development conversations relevant
to this project.

AI tools were used for coding assistance, debugging, test support,
documentation drafting, and experimental review.

The exported transcripts have been reviewed for credentials, personal
information, and organization/role identifiers. Minimal redactions are marked
explicitly where required for submission anonymity or secret protection.

Human-controlled decisions included problem framing, dataset selection,
evaluation design, benchmark design, experiment freezes, system selection,
held-out execution, and final interpretation.
